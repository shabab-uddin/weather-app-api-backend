
# Weather App

A weather application built with HTML, CSS, JavaScript, Node.js, Express.js, and the OpenWeather API.

## Features

- Search weather by city
- Display temperature and feels-like temperature
- Show humidity, wind speed, and weather conditions
- Handle invalid city names and API errors
- Keep the API key in a server-side environment variable

## Technologies

- HTML, CSS, JavaScript
- Node.js and Express.js
- OpenWeather API
- Git and GitHub

## Run Locally

1. Install Node.js.
2. Clone this repository.
3. Run `npm install`.
4. Create a `.env` file in the project root.
5. Add `OPENWEATHER_API_KEY=your_api_key` to `.env`.
6. Run `npm start`.
7. Open http://localhost:3000.

## Environment Variables

`OPENWEATHER_API_KEY` — your personal OpenWeather API key.


## Deployment

The application can be deployed as a Node.js web service. Configure the API key as a secret environment variable on the hosting platform.
